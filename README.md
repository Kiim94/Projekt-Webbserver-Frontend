# Projektuppgift för Backend-baserad webbutveckling, 2026

## Webbplatsen
[Klicka här för att komma till café Bönan](https://bonan.netlify.app/)
Detta är frontend-delen av projektuppgiften i backend-baserad webbutveckling. 

Denna frontend är menat för ett fiktivt café som heter Café Bönan. 
Applikationen kommunicerar med backend delen för att visa meny, recensioner och administrativ funktionalitet för inloggade medarbetare.

[Här är backend](https://github.com/Kiim94/Projekt-Webbserver)
## Funktioner
- Visa meny
- Läsa och skriva recensioner
- Inloggning av administratörer
- Hantera menyrätter
- Hantera användare

## Tekniker
- Vite
- SCSS
- HTML
- JavaScript

## Installation
```
git clone https://github.com/Kiim94/Projekt-Webbserver-Frontend.git
```

```
npm install
```
## Start
```
npm run dev
```
